# VIT

Персональный ИИ-агент — ядро VITON13 OS. Не чат-бот, который отвечает, а агент, который выполняет: вы ставите цель, VIT планирует шаги, ищет данные, подключает агентов и доводит работу до результата. Если задаче нужен человек — передаёт заявку команде.

Версия 0.1 · открытый тест.

## Установка

Нужен [Node.js](https://nodejs.org) 22.13 или новее.

```bash
git clone <адрес репозитория> vit
cd vit
npm start
```

Приложение откроется в браузере по адресу `http://localhost:5313`. У сервера нет зависимостей — `npm install` для этого не нужен.

Как отдельное окно на рабочем столе:

```bash
npm install
npm run app
```

## Модели

VIT не привязан к одной модели. Модели — это двигатели; VIT решает, какая работает над задачей, и переходит к следующей, если одна упёрлась в лимит, осталась без баланса или не отвечает.

**Локальная модель — бесплатно и без ключей.** Поставьте [Ollama](https://ollama.com) и скачайте модель:

```bash
ollama pull qwen3:4b-instruct
ollama pull bge-m3
```

Первая отвечает, вторая нужна памяти (поиск по смыслу). VIT сам найдёт их.

**Облачные модели — по желанию.** Ключ вводится в приложении (Настройки → Модели) или в файле `.env` (образец — `.env.example`): Claude, CometAPI, любой сервис с OpenAI-совместимым API.

Три режима: «Экономно» (всё локально, облако только при сбое), «Баланс» (сложная работа агентов — в облако), «Облако».

## Что внутри

| Раздел | Что делает |
| --- | --- |
| **VIT** | Разговор текстом и голосом. VIT сам решает: ответить, найти в интернете, провести цель через агентов или передать человеку. |
| **Память** | Граф: каждая мысль — узел, каждая связь — смысл. Восемь видов памяти: эмоции, настроение, знания, люди, цели, задачи, идеи, ваши слова. Любой узел можно удалить. |
| **Работы** | Материалы, которые собрали агенты: тексты и первая версия сайта. |
| **Заявки** | Задачи, переданные людям. Статус обновляется в реальном времени. |
| **Агенты** | Тринадцать ролей: стратег, исследователь, дизайнер, копирайтер, разработчик, SEO, реклама и другие. |
| **Настройки** | Модели, голос, инициатива, связь с командой, выгрузка и удаление данных. |

## Голос

Речь распознаётся на вашем компьютере через [whisper.cpp](https://github.com/ggerganov/whisper.cpp). Нужны `whisper-cli`, `ffmpeg` и модель `ggml-*.bin`:

```bash
brew install whisper-cpp ffmpeg
```

Модель положите в `data/models/` или укажите путь в `.env`: `VIT_WHISPER_MODEL=/путь/ggml-large-v3-turbo.bin`. Без этого всё работает текстом. Ответы озвучивает системный голос.

## Данные

Диалоги, память, работы и заявки лежат в папке `data/` на вашем компьютере: один файл SQLite и папка с материалами агентов. Сервер слушает только `127.0.0.1`. В облако уходит только текст запроса — и только если вы подключили облачную модель и до неё дошла очередь. Память для поиска по смыслу считается локально.

В Настройках всё можно выгрузить одним файлом или удалить.

## Вход

Через VITON ID (тот же аккаунт, что на viton13.com) или без аккаунта — с локальным профилем. Пароль уходит напрямую в сервис входа VITON ID и нигде не сохраняется.

## Заявки команде

Чтобы заявки мгновенно приходили исполнителям, подключите Telegram-бота: Настройки → Связь с командой (токен бота и ID чата). Сторона исполнителей — страница `/team`: там меняют статус, и человек сразу видит это в приложении.

## Устройство

```
bin/vit.mjs        запуск: сервер + браузер
electron/main.cjs  окно на рабочем столе
server/
  index.mjs        HTTP-сервер и API
  agent.mjs        VIT: маршрут сообщения, цель через агентов, инициатива
  ladder.mjs       лестница моделей и переключение между ними
  memory.mjs       память-граф: извлечение, связи, поиск по смыслу
  agents.mjs       тринадцать ролей
  tools.mjs        поиск в интернете и чтение страниц
  team.mjs         заявки людям и Telegram
  auth.mjs         VITON ID и локальный профиль
  voice.mjs        распознавание речи
  site.mjs         шаблон сайта, который собирает разработчик
web/               интерфейс: без сборки, чистые модули
```

## Что VIT пока не умеет

- Покупать, платить и оформлять заказы сам — такие задачи уходят заявкой людям.
- Работать на телефоне как отдельное приложение: Android и iPhone — следующий этап.
- Маленькая локальная модель ошибается чаще облачной. Важное проверяйте.
